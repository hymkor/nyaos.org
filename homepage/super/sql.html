ページング

何万件中、n 番目から 10件だけを取り出す場合、Oracle 8 だと困る。つーのも、

    select * from T_LIST 
     where rownum >= ?
       and rownum < ?
       and (その他、もろもろの条件)
     order by T_LIST.SERIAL_NO ;

等としても、１件もヒットしないからだ。

聞くところによると、Oracle 8 移行では、rownum の解釈が正しくなったらしく、 検索した後の結果に対して番号がふられるとのこと。 つまり、「rownum >= ?」は ? が1以外の場合、決して満たされない。 最初の行は必ず rownum = 1 になるからだ。

ではということで、サブクエリを使う技がある。

select … from ( select rownum LINENO , SERIAL_NO… from T_LIST where (その他、もろもろの条件) order by T_LIST.SERIAL_NO ) qry where qry.LINENO >= ? and qry.LINENO < ? ;

ところが、これ Oracle 8i からしか駄目であるそうな。
