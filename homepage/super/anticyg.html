Cygwin 抜きの UNIX ライクな環境の構築

Cygwin は Windows で UNIX のような操作環境を築くための デファクトスタンダートとなっています。 しかしながら、まだまだ Windows95 をはじめとする DOS 由来の Windows シリーズでは不安定といわざるをえないようです。 また、Cygwin の導入は結構ハードルも高く、あまり気軽とはいえません。 そこで、比較的手軽に UNIX 的な環境を構築できるツールを集めてみました。

Nide Tools Library

UNIX-like tools mv,cp,rm などの基本ツールを収録した UNIX-Like tools や、UNIX の #! を DOS 上で実現する SOS がここからダウンロードできます。

NT版UNIX-like tools

株式会社ピーデーの川俣氏により、 UNIX-Like tools を NT 環境に移植されたものです。

ActiveScriptRuby

オブジェクト指向スクリプト言語 Ruby の Windows 版バイナリの一つです。 公式パッケージではありませんが、この arton さん提供のものは、 Microsoft Installer 準拠で、 ダブルクリック一つでインストールできるので、お薦めです。

なお、Web Server の都合で、Netscape 4 では、 このバイナリは正しくダウンロードできないそうですので、 注意してください(IE か wget を使用ください)。

Digital Mars C and C++ Compilers

元Zortech/Symantic C++ であるところの Digitalmars C++ です。 現在はフリーウェアになっています。 DOS の 16bitアプリから、Windows 向けの 32bit アプリまで、広く対応しています。 UNIX Like というわけではありませんが、CUIの開発環境としては Borland系と並び、重宝します。

Nihongo Yet Another DOS Shell

最後に拙作のコマンドラインシェルを紹介します。 tcsh の操作性を模しつつ、Windows 向けと思われる 機能を実装したコマンドラインシェルです。 16bitアプリケーションであるので、 コンベンショナルメモリを多く(120KB)消費するのが欠点ですが、 きょうび、コンベンショナルメモリ自身を使用するアプリは少ないので、 特に支障はないでしょう、きっと。
