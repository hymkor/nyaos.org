<h1>もんじょスタイル(mjDiary)</h1>

tDiary の日記記述フォーマットです。
etDiary をベースとしており、これに wiki 等の文法を適当に織り込んでいます。

|| <a href="./mjdiary_style-20050110.zip">mjdiary_style-20050110.zip</a> |
    <%= File.stat("mjdiary_style-20050110.zip").size %> bytes 

<ol>
    <li>zip ファイルを展開。</li>
    <li>サーバ上の tdiary ディレクトリに mjdiary_style.rb を ASCII 転送。
	<br>（作ったのが Windows 上なもんで、すみません）</li>
    <li>tdiary.conf の @style を 'mjdiary' にする。</li>
</ol>

<h2>特徴</h2>

<h3>アンカータグを簡単に書くことができる。</h3>

URL の後に中括弧で囲まれた被アンカー文字列を書くだけで、
リンクが張れます。

<pre>
    http://example.net/index.html{ほげほげ}
	    ↓
    <a href="http://example.net/index.html" target="_blank">ほげほげ</a>
</pre>

表示上は「http://example.net/index.html{ほげほげ}」のようになります。
この変換は、http<!-- -->: で始まる文字列のみが対象です。

<h3>箇条書(wiki風)</h3>

先頭が「*」で始まる段落は、&lt;ul&gt;タグに置換されます。

<pre>
* ひとつ目
* ふたつ目
    :: ← 改行させて、1インデント入れる記号
* みっつ目
</pre>

次のような表示となります。

* ひとつ目
* ふたつ目
    :: ← 改行させて、1インデント入れる記号
* みっつ目

「<tt>::</tt>」は、&lt;br&gt;&amp;emsp; に変換されますので、
携帯で見ると化ける場合があります。


<h3>DLタグ</h3>

先頭が「:」で始まる段落は、〈dl〉になります。

<pre>
:ひとつ目
    :: ザク
:ふたつ目
    :: グフ
:みっつ目
    :: ドム
</pre>

:ひとつ目
    :: ザク
:ふたつ目
    :: グフ
:みっつ目
    :: ドム

wiki と違って別に１行に無理矢理収める必要はありません。

注意すべき点としては「<code>*</code>」「<code>%</code>」
「<code>:</code>」「<code>::</code>」の前には空白以外の文字を
入れてはいけません。

<pre>

    | うふふふふふ

この表は、class=&quot;framed&quot; とクラス指定されています。

<h3>256倍風センタリング</h3>

<pre>
>>こんな風な感じです<<
</pre>

>>こんな風な
感じです<<

HTML的には

<pre>
<p align="center" align="OxFF">
    こんな風な感じです。
</p>
</pre>

となります。なお、最初の 0 はゼロではなく、英字のオーです。
さらに、大文字・小文字も区別されるので、注意ください（ひどい）

<h1>もんじょテキストフォーマッタ</h1>

上と同じような文法で、ローカルで html を作成するための、フォーマッタです。

<pre>
    mjdoc.rb foo.css foo.mj >foo.html
</pre>

のように使用します。だいたいの文法が、もんじょスタイルと同一です。
