もんじょスタイル(mjDiary)

tDiary の日記記述フォーマットです。 etDiary をベースとしており、これに wiki 等の文法を適当に織り込んでいます。

mjdiary_style-20050110.zip 3880 bytes
  1. zip ファイルを展開。
  2. サーバ上の tdiary ディレクトリに mjdiary_style.rb を ASCII 転送。
    （作ったのが Windows 上なもんで、すみません）
  3. tdiary.conf の @style を 'mjdiary' にする。

(2005.01.10)

  • http://～{…} を <<～>> の中にも書けるようにした。
  • recent_list で、目次の数字がずれるのを修正した。 (etDiary の 2004年8月前後の修正を取り込んだだけ)
  • EUC のコメントを入れてしまいました。 SJIS にコンバートすると動作しなくなりますので、 ftp 転送時はご注意ください。

特徴

アンカータグを簡単に書くことができる。

URL の後に中括弧で囲まれた被アンカー文字列を書くだけで、 リンクが張れます。 

    http://example.net/index.html{ほげほげ}
	    ↓
    <a href="http://example.net/index.html" target="_blank">ほげほげ</a>

表示上は「ほげほげ」のようになります。 この変換は、http: で始まる文字列のみが対象です。

箇条書(wiki風)

先頭が「*」で始まる段落は、<ul>タグに置換されます。 

* ひとつ目
* ふたつ目
    :: ← 改行させて、1インデント入れる記号
* みっつ目

次のような表示となります。

  • ひとつ目
  • ふたつ目
      ← 改行させて、1インデント入れる記号
  • みっつ目

「::」は、<br>&emsp; に変換されますので、 携帯で見ると化ける場合があります。

DLタグ

先頭が「:」で始まる段落は、〈dl〉になります。 

:ひとつ目
    :: ザク
:ふたつ目
    :: グフ
:みっつ目
    :: ドム
ひとつ目
ザク
ふたつ目
グフ
みっつ目
ドム

wiki と違って別に１行に無理矢理収める必要はありません。

注意すべき点としては「*」「%」 「:」「::」の前には空白以外の文字を 入れてはいけません。

表

|| 枠11 | 枠12
|| 枠21 | 枠22
|| わくわくわくわく
    | うふふふふふ
枠11 枠12
枠21 枠22
わくわくわくわく うふふふふふ

この表は、class="framed" とクラス指定されています。

256倍風センタリング

>>こんな風な感じです<<

こんな風な 感じです

HTML的には 

<p align="center" align="OxFF">
    こんな風な感じです。
</p>

となります。なお、最初の 0 はゼロではなく、英字のオーです。 さらに、大文字・小文字も区別されるので、注意ください（ひどい）

もんじょテキストフォーマッタ

上と同じような文法で、ローカルで html を作成するための、フォーマッタです。 

    mjdoc.rb foo.css foo.mj >foo.html

のように使用します。だいたいの文法が、もんじょスタイルと同一です。
