YA*OS のリダイレクトを未だぐずぐずやってるのことよ。

Borland C++ では、fopen した直後だと、アペンドオープンしても実際に書き出すまでは、ファイル書込み位置は末尾に移動していないらしい。どうも putc などで書きこむ直前に移動しているようで。

    FILE *fp=fopen( fname , "a" );
    dup2( fileno(fp) , 1 );
なんてことをしてハマってしまった。

    FILE *fp=fopen( fname , "a" );
    fseek( fp , 0 , SEEK_END );
    dup2( fileno(fp) , 1 );
ということをして、とりあえず、回避。

ライブラリのバグと言いたいところだが、高水準ファイル入出力と低水準ファイル入出力を混在させて使うという、禁止技を使っているわけだから、文句は言えないわけで…(^^;;

素直に低水準ファイル入出力で統一した方がいいのだろうか。まぁ、いいや。動いてんだし。(その思想は危険です)
