月号の UNiX MAGAZINE によりますと、Cygwin のリーダーの人というのは、結構、ワガママで、リリースすると言ったら、絶対リリースしてしまうとのことで。

なーんか、納得。

というのも、OS/2 の世界にも、Cygwin と同じようなものとして、emx というものがありますが、こちらは「不安定」なんつーことは全然なし。OS/2 そのものが Windows9x と違って、安定しているからといっても、folk とか signal の実装については Windows 系と同様に難しい問題であるはずで、なんで、それほど違うのかと思っていましたが、こういうことだったんですね。

Windows では、最近になって、Mingw32 で DLLほぼ不要実行ファイルを作れるようになったそうですが、OS/2 はほとんど最初から emx でDLL不要実行ファイル作れていましたし、だいぶと前から XFree86 も動いていました。この差はいったいどこから来るんでしょう。

最近、もっぱら、Windows9x の DOS窓ばかり使うようになってしまいましたが、いくら自分でコマンドラインを強化してもやはり、OS/2 の方が強力だなと思わざるをえません

  • NT のコマンドプロンプトはエスケープシーケンスが効かないので、非常に貧相。でも、スクロールバーがあるのがいいなぁ。
  • 9x のDOS窓では、32bitアプリは日本語を入力できないし、16bitアプリではパイプがテンポラリファイルになってしまう。
  • OS/2 は標準で、telnetd とかあるし。

こうして見ると、OS/2 Prompt こそが最強のコマンドラインですねぇ。やはり。

という感じに、久しぶりに OS/2 を誉めまくってみました、どんなもんでしょう。ただ、これをやると、Windows系の人がヒキまくってしまうという可能性もなきにしもあらずなのですが...
