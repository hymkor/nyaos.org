太陽にホイール(2001/04/28)

Digitalmars C++。 検索エンジン等で見ても全然ひっかからない。 なんでだろ。結局、Turbo C++,Borland C++ に対する強みというのが、

  • 最新のC++の仕様の DOS/Win16 アプリを作成できる。

という点しかないかしらん。Turbo C++ 1.01 では

  • template が使えない
  • 例外が使えない
  • クラスの入れ子をしても、名前空間内のローカルクラスにならない

とか、C++愛好者としては非常に不満なんですよね〜。 Borland C++ は、これらをサポートしているけども、 DOS(Win16)アプリケーションは作成不能だし...

Digitalmars C++ はこれら両方を兼ね備えているので、ぜひとも、 乗り換えたいんだけども、一人ではちょっとねぇ。(^^;; なお、NYADOS のソースは Digitalmars C++ 対応です(Makefile.sc を使いましょう)。

★≡≡≡≡

NYAOS のヒストリは tcsh + Vz + bash です。 基本は tcsh なんですが、
  • Ctrl-R などの、ヒストリのインクリメンタルサーチは bash 由来
  • Ctrl-P で引数単位のヒストリ参照は Vz 由来

です。後者は、おそらく tcsh にはなかったと思います。 tcsh で同様のことをするならば、「cd !$」とかの ヒストリ参照演算子(?)を使った方法になるのではと思います。

ちなみに「bind ws」みたいなコマンドは NYAGOS では内蔵コマンドで 用意する予定はありません。WordStarライクなキーバインドを設定する 設定ファイルを付属させるのはアリだとは思いますが。 NYA*OS 以外のシェルでは...一括設定機能は、あると思います。 bash や tcsh はちょっと知りませんが、ksh には emacs 型編集モード、vi 型編集モードを１コマンドで設定できたと 思います。って、emacs と vi ぢゃ、DOS系の人々には意味がないでしょうね。 地道に１キーごとに設定するしかないかも。 (１キー単位でのキーカスタマイズはできたはずですよ)

フォローついでに 前におっしゃっていた「eff を Linux へ移植してー」という件ですが.. Linux 用(いや、UNIX汎用か)のファイラーとしては、 FD/Clone というのがあります。これが OS/2 に移植されていたら、 eff は存在しなかっただろうという代物です。 カスタマイズも出来たと思います。 RPM形式で存在しているかどうかわかりませんが、 一応、お薦めしておきます。 が、基本的には UNIX の中に DOS 文化をそのまま持ちこもうとするのは 余りよろしくないと思います。。。。

しかし、Linux そんなに不便ですかー。 私は、やはり成長環境が UNIX だったせいもあり、 Linux は快適で仕方が無いんですけど(笑)。 Linux を使っていると、やはり UNIX 系ツールの標準装備度が OS/2 とは全然違いますから...って、当たり前だろ、おい。

余談ですが、「肥大化したnyaosは外人さんに投げて、 nyagosを元に一からやり直して欲しかったりするのです」 というのは、ほぼ同感です。 eff も NYAOS も設計的にも破綻しているので、もう手放したいです。 ただ、外人さんに投げるのはちょっとつらいものがあります。 コミュニケーションの問題もありますし、 DBCS・かんななど、理解してもらえない箇所が結構ありますからね。 出来るなら、日本人に管理をお願いしたいです。 どなたか引き受けてくれる人いませんかねー (って、作者でさえをサジを投げているというに、いるはずねぇぇぇ)。
