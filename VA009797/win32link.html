Ruby-mswin32
オブジェクト指向スクリプト言語Ruby の mswin32版(Visual-C++)です。 Windows の標準スクリプト言語にすべきですね、うん。
Nide Tools Library
新出尚行先生を始めとする方々が作成した、 DOS/Windows上で UNIX ライクな環境を実現するツールの転載サイトです。
  • UNIX-Like tools (cpやmv などのツール集)
  • SOS (スクリプト言語の実行支援)
単純な GPL 配布ではなく、複数の作者の方々の コードが入っているため、著作権が複雑なのがアレですが、 基本的にソースを公開したフリーソフトウェアです。 DOS系ソフトですが、Windows95 の LongFileName に対応しています。
コマンドラインシェル NYA シリーズ
tcshライクな環境を実現する拙作のコマンドラインシェルです。 Win16環境用の NYADOS と Win32環境用の NYAGOS(NYACUS)があります。
